# Features

discord-web-manage の機能概要です。

## ダッシュボード

- メンバー数・オンライン数などの KPI
- 参加トレンド（グラフ）
- フィルター発火状況のサマリー
- 最近の操作・アクティビティ

## Bot 管理

| 機能 | 説明 |
|---|---|
| ステータス | Bot の接続状態・レイテンシ確認 |
| アクティビティ | Presence（オンライン / 退席中 等）の変更 |
| メッセージ送信 | テキスト / Embed / 添付ファイル、スレッド返信、フォーラム新規投稿 |
| Bot 投稿履歴 | Bot が送ったメッセージの一覧・編集・削除 |

## メンバー / メッセージ管理

| 機能 | 説明 |
|---|---|
| ユーザーリスト | ギルドメンバー一覧・プロフィール |
| メッセージリスト | Discord API 検索によるメッセージ参照 |
| 手動処置 | BAN / Kick / ロール付与 / メッセージ削除 |

## 自動フィルター

### メッセージフィルター

| フィルター | 内容 |
|---|---|
| メッセージ DB | フィルター対象メッセージの蓄積・事後処置 |
| ワードフィルター | NG ワード一致 |
| 重複フィルター | 同一内容の連投検知 |
| モデレーションフィルター | OpenAI Moderation API（テキスト・画像） |

### メンバーフィルター

| フィルター | 内容 |
|---|---|
| 参加 DB | 参加イベントの記録・事後処置 |
| 名前フィルター | ユーザー名 / ニックネーム |
| 参加直後フィルター | 参加から一定時間以内の行動 |
| プロフィールモデレーション | プロフィール内容の AI チェック |

### 共通

- チャンネル allow / block リスト
- 通知チャンネルへの Discord 通知
- 自動処置: メッセージ削除、BAN、Kick、ロール付与（フィルター設定に依存）
- 操作は Bot 名義で実行され、**操作ログ**に記録

## 設定

| 機能 | 説明 |
|---|---|
| 管理者ユーザー | Web UI にログインできる Discord ユーザーの管理 |
| 操作ログ | 管理者の手動操作 + Bot の自動処置の監査ログ |

## 言語

Web UI は日本語 / English に対応（vue-i18n）。

## 今後の予定（ロードマップ）

- ロール管理テーブル

## 設計上の制約

- **1 ギルド限定** — `DISCORD_GUILD_ID` 指定
- **JSON ストア** — 大規模・マルチインスタンス構成には非推奨
- **Web 管理者権限** — 現状は全管理者が同等権限（ロールベース ACL は未実装）
